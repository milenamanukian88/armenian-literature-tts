# Armenian Literature Text-to-Speech Tool

A web-based accessibility tool that allows users to listen to
Armenian literary works in English using text-to-speech technology.

## Project Overview

The goal of this project is to make Armenian literature more
accessible, particularly for visually impaired users and auditory
learners.

Users can select a literary work and listen to the full text using
text-to-speech functionality while customizing the reading experience.

## Features

- Select from multiple Armenian literary works
- Text-to-speech playback
- Play and pause functionality
- Replay audio
- Adjustable reading speed
- Selection of available English voices
- Adjustable text size
- Accessible reading interface

## Literary Works

The project includes works by Armenian authors such as:

- Anna Davtian
- Sargis Hovsepyan
- Levon Khechoyan
- Aksel Bakunts
- Hovhannes Tumanyan
